# 环境适配

先在**演练用虚拟机**里配好工具，再开工。逐项填「路径 / 是否可用 / 版本」：

| 类别 | 需要确认的 |
| --- | --- |
| 网络 | 出口 IP、代理、DNS、目标网段可达性（`ping`/`nc -z`） |
| 侦察 | 被动数据源凭据（放 `~/.dsh/.credentials.yaml`，不要写进仓库） |
| 执行 | 需要的运行时（python/node/工具二进制）与路径 |
| 通道 | 跳板/VPS 是否就绪、带宽与稳定性 |
| 留证 | 截图目录、日志目录（默认 `$DSH_HOME/purge2/lab/`） |

填完把「缺什么」一次性列给操作者，**不要边缺边试**——那会浪费步数并把环境搞乱。
